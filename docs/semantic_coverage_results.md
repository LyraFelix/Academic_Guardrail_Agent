记录日期：2026-11-01。

身份与措辞补充：本页的客户端是本次对话中的 **Codex 助手**，没有调用仓库内置的大模型或独立配置的模型 API。底层具体模型 ID 未提供。“过于保守”不能仅由一次标签分歧诊断出来；本页按原始标签保留分数，并将该例描述为具体干预表述与证据的对应分歧。后续扩样另记于 `client_evaluation_results.md`。

第四阶段的 76.11% 复核与 23.89% 证据不足应合计理解为 **339/339 没有得到具体规则判断**。前者不是全部人工负担，后者也不是核验成功。本轮保留旧报告和全部原始数据，先修可复现的文本处理缺陷，再接入用户已有客户端完成语义判断。

结论分两部分：修规则后，原 339 个配对仍全部未解决；另一次 12 个公开 train 配对的实际客户端试跑，给出 6 个支持/反驳判断和 6 个证据不足，全部标签与数据集一致 11/12。不能把后者写成通用的 91.67% 准确率，也不能把证据不足算作已经验证论断。

## 1. 改动及作用

- 保留可用证据单元上下文，避免同位语逗号把主体切掉；数字抽取避开部分 Unicode/连字符实体标识符。
- 明确匹配不再被弱背景候选否决；真正的反证、数字疑点或相互冲突证据仍阻止直接通过。
- 一个 MCP 服务新增准备、分页读取、记录三种工具。客户端负责语义判断；服务端检查证据快照、编号、逐字引用和阅读声明。
- 记录 `CLIENT_MODEL` 来源与 `semantic_judgment_verified=false`，不把机械引用校验冒充推理正确性。
- 评测固定输入、gold、证据包与提交的哈希，保留错误分母；单独报告支持/反驳、NEI、弃判和错误。

上游本地全文按块抽取，可能已经在句中结束，因此保留上下文并不保证获得原始完整句子或全文。CLI/旧 HTML 仍展示规则结果，新语义结论在客户端回复与单独 review JSON 中。

## 3. 实际客户端试跑

### 协议

- 使用相同固定官方 SciFact archive，SHA-256 为 `11c621288d41ac144d29b13b0f8503b3820b7d6e8b1f6ff24dff335c196d76be`。
- 从公开 train 的 919 个唯一 cited pairs 中，按 `sha256(client-review-pilot-v1:claim_id:doc_id)` 升序取前 12 对，选择过程不使用标签。这是 12 条不同论断，不是官方 test 集，也不能保证不在模型预训练数据中。
- 输入为论断和完整给定摘要，没有给判断过程提供 gold 标签或标注证据句索引；不测全文检索、文献身份或真实撤稿覆盖。
- 当前交互式助手读取 MCP 实际返回的全部证据，选择结论、五项理由与引用编号。小脚本仅把已选编号的原文复制成准确引用并写 JSONL，没有按标签生成或修改结论。因此引用通过率也不能解释成自由生成引用的可靠性。
- 先冻结 12 条判断，再实际调用 `record_claim_review` 保存，最后打开 gold 评分。中途修复了快照绑定，重新准备同一输入；逐项比较确认原文、顺序、元数据与规则提示不变。旧包和新包都保留，判断未重写。
- 实际提交固定在干净提交 `93840cb6c57f07b6ae2e3644aa25db6dc32a204a`。此客户端的具体模型 ID、采样参数、token/费用数据没有由运行环境提供，标为 `interactive_assistant_unspecified_model`，不猜测。
- 所有 MCP 服务端步骤的 HTTP/模型初始化边界记录为空。客户端正在进行模型推理，所以不能称为“零模型成本”；没有另行发出模型 API 请求。

### 结果

| 实际输出 | 数量 | 与标签一致 |
| --- | ---: | ---: |
| SUPPORTED | 5 | 5 |
| CONTRADICTED | 1 | 1 |
| NOT_ENOUGH_EVIDENCE | 6 | 5 |
| UNCERTAIN / ERROR | 0 | 不适用 |
| 全部 | 12 | 11 |

- **支持/反驳覆盖：6/12 = 50%。** 这六个判断均匹配标签，样本很小，尤其只有一个反驳判断。
- **证据不足：6/12 = 50%。** 其中五个原本就是 NEI，说明材料未建立论断；另一个是漏掉的 SUPPORT。不能把这六个都计为成功解决，也不能要求系统对真正缺证据的材料强行判断真假。
- **全样本标签一致：11/12。** `label_coverage=12/12` 仅表示都给出了三分类标签，不是 100% 核验完成。
- 没有 UNCERTAIN 不代表不需人工判断：NEI 可能需要补材料，模型已有结论也可能出错。本轮没有测量人工节省时间。

唯一不一致配对为 `382:11659421`。论断描述通过向培养系统添加分子来模拟环境引发的衰老；摘要描述通过 progerin 表达在细胞模型中诱导衰老。Codex 助手认为具体干预方式不足以对应，给出 NEI；数据集标签是 SUPPORT。计分按原始 gold 算错，保留判断与理由，不为了改善结果改标签。这确认了表述对应上的分歧，不能单凭该例证明模型普遍保守，也没有证明原始标签错误。

其余例子体现了需要上下文推理的地方：增长数量不能直接推出当前总量排名、整体过敏终点不能代替湿疹子终点、Satb1 对 PD-1 的作用不能直接反转为 PD-1 对 Satb1 的因果结论。这些是对已保存个案的解释，不是按错误类型统计的泛化结果。
