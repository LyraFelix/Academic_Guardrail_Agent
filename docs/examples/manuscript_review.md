# Rechecking the SimCLR training setup

SimCLR uses a default batch size of 256 for 100 epochs [1].

The default SimCLR training run lasts 100 epochs [1].

The background bibliography includes a paper published in Nature in 2014 [2].

The protocol also cites a pilot comparison for which no reference file was supplied [3].
