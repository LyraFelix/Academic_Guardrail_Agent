# 第四阶段实测：流程可以复现，真实摘要上的冲突识别仍不足

记录日期：2026-11-01。

本阶段完成了评测流程整改，并实际运行了固定版本的 SciFact dev 数据。当前离线规则在 **339 个配对中发出 0 个具体冲突告警，71 个 CONTRADICT 配对的告警召回为 0/71**。258 个配对进入人工复核，81 个显示证据不足，没有运行异常。

这说明工程流程能够稳定运行，但当前规则在这批真实科学摘要上尚不能有效识别矛盾。不能用“没有误报”证明判定可靠，也不能继续用历史的 97.2% 描述当前系统能力。零告警时查准率没有定义，记录为 `null`。

补充解读：258 个复核与 81 个证据不足合计 **339/339 未解决**，不能只把 76.11% 复核率看作全部剩余工作。后续规则修复与客户端工作流另记于[语义覆盖整改实测](semantic_coverage_results.md)，本页历史运行数据保持原样。

## 1. 本次究竟测了什么

- **系统版本**：生产 `src/` 保持第三阶段提交 `9e9365d13296cb0bc9f40da13dce275c7c8d753a` 的内容不变；评测实现固定在 `0dbf069f789409dfbfb637babef67d1e10739420`，运行时工作区干净。没有根据本次预测结果调整语义规则、阈值或样本。
- **输入**：300 条 dev 论断及其所有不同的所引文献，共 339 个唯一配对；每对提供完整摘要。模型接口不接收标签、预期状态或标注证据句索引。
- **标签**：SUPPORT 138、CONTRADICT 71、NEI 130。原 archive 有 340 次引用；claim 1245 对 document 7662395 重复一次，准备 manifest 明确登记去重，原 archive 保持不变。
- **执行模式**：关闭嵌入模型，使用既有规则和词面匹配；不调用 LLM、在线学术 API，不下载模型。所有正式运行的离线越界尝试记录均为空。
- **比较对象**：`overlap` 只选词面最相似的完整句子，阈值预先固定为 0.50；`always_review` 始终要求复核。两者使用相同输入，均为简单诊断对照。

这属于“给定所引文献完整摘要”的规则诊断，没有测试从全部 5,183 篇文献中检索、稿件解析、引用身份消歧或在线撤稿覆盖。它与 [官方 SciFact 检索、标签及证据评测](https://github.com/allenai/scifact/blob/master/doc/evaluation.md) 不同。dev 已出现在项目历史评测中，不是从未接触过的留出集。四种复核状态也不能直接当作三类事实标签计算总准确率。

旧脚本按其样本选择逻辑得到 323 行，其中只有 322 个唯一配对；新协议去掉重复行并补回遗漏的 17 个 NEI 配对，得到 339 个唯一配对。因此旧、新百分比不能直接比较。

## 3. 为什么合成样例通过，真实数据仍然很弱

第三阶段的 50 个合成开发样例仍然全部符合预期状态和提示代码：数字 14/14、否定 12/12、因果 4/4、范围 11/11、证据处理 9/9。这些样例参与了规则开发，只证明已知场景未退化，不证明泛化准确率。

对本轮全部原始输出统计后，可以看到几个具体限制：

1. **可比性检查过于严格。** 258 个 REVIEW_REQUIRED 配对全部带有 `COMPARISON_UNCERTAIN`。当前 `comparison_uncertain()` 要求解析后的主体、结果词集合相同；解析不到关系时，还会退回接近字面一致的判断。`ClaimEvaluator._check_pair()` 会把可比性不确定或条件变化下的差异降为复核。这是能从代码追到的状态生成路径；本轮没有做消融实验，不能给每个检查分配独立的性能损失。
2. **主摘录选择经常没有带回关键证据。** 在 71 个矛盾配对中，主摘录只有 28 个触及标注证据句。全部有标注证据的 209 对中，只有 25 对的主摘录完整覆盖一组证据句。短分句有时保留了实体，却截掉了关系或结论。
3. **限定提示很多，但提示价值尚未验证。** `SCOPE_OMITTED` 出现在 191 对，其中 101 对的金标为 SUPPORT。不能直接把这 101 对都算作错误：措辞审查与 SciFact 真值任务不同；同样也不能把这些提示数量当作有效发现数量。
4. **有限规则表仍有覆盖缺口。** 代码覆盖与失败例提示，关系改写、实体别名、比较对象反转、倍数与区间、被动句和跨句解释可能是覆盖缺口。本轮没有为这些表达逐类标注和统计，不能给出各类错误率；简短的同句式开发样例不足以验证这些能力。

| `51:45638119` | 论断谈 ALDH1 与更好的乳腺癌结局，标注证据谈较差预后；主摘录选到了研究方法的背景句，状态为复核。 |
